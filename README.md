# OLA Data Analysis Project

## Project Overview
This project is an in-depth analysis of OLA ride data, visualized through a comprehensive Power BI dashboard. The dashboard consists of five pages, answering various business questions related to ride volume, customer and driver ratings, vehicle types, booking statuses, revenue, and more.

The aim of this project is to provide insights into OLA's ride-hailing service by examining key performance indicators (KPIs) across different dimensions such as ride distance, payment methods, customer ratings, and booking statuses.

## Tools and Technologies Used
- **Power BI**: For creating interactive and visually appealing dashboards.
- **Data Analytics**: Techniques applied for data processing, cleaning, and analysis.
- **DAX**: Used in Power BI for creating calculated measures and columns to enhance the visualizations.

## Dashboard Pages

### Ride Volume Over Time
### Booking Status Breakdown
### Top 5 Vehicle Types by Ride Distance
### Average Customer Ratings by Vehicle Type
### cancelled Rides Reasons
### Revenue by Payment Method
### Top 5 Customers by Total Booking Value
### Ride Distance Distribution Per Day
### Driver Ratings Distribution
### Customer vs. Driver Ratings

## How to Run the Project
1. Open Power BI Desktop.
2. Import the OLA ride dataset into Power BI.
3. Load the dashboard file and explore each of the five pages to analyze the key metrics and insights.
